*# Financial Health Dashboard for SMEs*



*## Project Overview*



*This project is an interactive Power BI dashboard designed to analyze the financial health of Small and Medium Enterprises (SMEs). It provides insights into financial performance through Income Statements, Balance Sheets, Cash Flow analysis, and forecasting to support budgeting and financial planning.*



*---*



*## Objectives*



*- Visualize Income Statement metrics (Revenue, Expenses, Profit)*

*- Analyze Balance Sheet components (Assets, Liabilities, Equity)*

*- Monitor Cash Flow performance*

*- Analyze profitability trends over time*

*- Forecast future Revenue and Profit*

*- Support financial planning with interactive dashboards*



*---*



*## Tools Used*



*- Microsoft Power BI Desktop*

*- Microsoft Excel*



*---*



*## Dataset*



*A sample financial dataset was created in Microsoft Excel containing 36 months of financial data (2023–2025).*
